# 0.5.3 发布验收记录

日期：2026-10-10。配套版本为后端 0.5.3、前端 0.5.2、Agent 0.5.3。本轮新增宿主凭据网页管理和布局修复，只发布前后端镜像；Agent 二进制、现有服务器和真实虚拟机不作变更。

## 本轮变更

- 宿主列表仅向管理员返回独立凭据状态、代次和更新时间，不返回令牌或摘要；沿用现有签发接口，无新迁移、依赖或 Agent 协议变化。
- 管理员从宿主卡片签发 / 轮换原宿主凭据，核对目标名称、UUID、管理 IP 和维护条件；只在本次弹窗返回令牌，支持独立复制及两行 agent.env 导入。
- 在途签发阻止重复点击和误离开；尚未保存时关闭 / 导航 / 退出有确认，关闭、会话切换和 pagehide 清除一次性持有对象，令牌不写浏览器持久存储或日志。
- 列表搜索和筛选使用统一紧凑工具栏；平台策略为全宽资源、自动续期、历史保留三组卡片，仍共享一次提交；历史归档保留下载、校验、独立备份和精确清理保护。
- 完整新手手册、推荐组合、内置 / 外置 Compose 默认标签和三个仓库的文档同步。原现场 144 / 172 记录保留最近实测版本，不把发布当作部署。

| 静态与已知漏洞 | Go 1.27.2 下 go vet ./... 通过；固定 govulncheck v1.8.0 通过，输出 No vulnerabilities found。不是零漏洞保证或宿主系统软件包审计。 |
| 前端回归 | 45 项 Node 测试全部通过；63 个脚本语法检查通过，入口 / 控制台静态引用无缺失，运行时输出、配置、凭据和 HAR 不被跟踪。 |

上述浏览器数据为隔离验收数据，未向生产宿主、LDAP 或群机器人发起操作；不将此记录解释为新增真实 KVM 创建 / 删除验收。临时浏览器验收库已清理，截图仅供页面对比。

## 发布门禁与产物

- 后端固定标签 lixiaokun/vmp-backend:0.5.3；前端固定标签 lixiaokun/vmp-frontend:0.5.2。
- 标签工作流先运行回归；发布前确认固定标签未被占用，无法确认或已存在时停止，不覆盖旧固定版本。
- 构建 Linux amd64 / arm64 镜像；推送后读取 OCI 清单并检查两种 Linux 架构。具体流水线结果与产物摘要以对应 GitHub Release 和发布工作流为准，工作流未通过不能视为已发布。
- Agent 继续使用原 v0.5.3 安装包和 SHA256SUMS，不重新上传旧资产；仅同步在线部署说明。

## 升级边界

已正常运行后端 0.5.2、前端 0.5.1、Agent 0.5.3 且独立身份有效时，本轮只更新前后端镜像，不新增配置项，不要求重装或重新签发 Agent。保留数据库、密钥、宿主名称 / UUID、账号、目录和状态。最高迁移仍为 020，后端启动仍校验台账。

旧 0.4.x 共享令牌或仍旧版 Agent 的环境，按[完整部署手册](新手部署手册.md)执行原宿主独立身份迁移，不能只换后端继续使用旧共享令牌。管理员主动轮换时仍须停目标 Agent、排空在途任务并只读导入验证，再手动恢复调度；网页按钮不会代替宿主上的配置修改。
