# 0.5.4 发布验收

配套：后端 0.5.4、前端 0.5.3、Agent 0.5.4。日期：2026-10-10。旧固定标签不覆盖。

## 本次范围

- Agent 校验 arping / ping 为 iputils，解析真实目标回应、MAC 和收发统计。Thomas 同名实现、参数 / 权限 / 网桥 / 取消 / 超时 / 无证据错误全部返回 IP_PROBE_FAILED，不产生占用结论。
- 创建真实冲突必须同时包含 IN_USE 状态、匹配的非空目标 IP，且没有已有域证据，才隔离和换候选。每轮最多 64 个冲突候选，过期 / 取消 / 失效用户不自动续建。
- 管理员单 IP / 有限批次异步复核，只有一次新的可靠空闲结果才安全解除；已分配 / 预留 / 保留期绑定禁止操作。批量公平推进并区分已确认占用与尚未复核 / 异常数量。
- 失败创建无 FREE 地址时可自动复核隔离候选，成功后原子恢复原预留和 CREATE，不重复扣预算。异常停止，取消 / 过期 / 目标变更 / 身份代次变化不解除、不重建。
- 已停止域开机 / 恢复前检查原 IP，冲突不启动、不换 IP、不删盘。恢复失败保留原租期、保留截止、IP、预算和恢复次数，启动成功才消耗一次机会。
- 复核任务 10 分钟未领取自动关闭；执行受任务租约限制，同领取结果幂等确认，不复用旧领取代际的探测结论。
- 021 自动迁移，新增数据字段和活动复核唯一索引，旧 001–020 迁移不修改。无新增必填环境变量，必须同时更新 Agent。

## 隔离验证记录

### Agent 与真实 Linux 探测

使用 Go 1.27.2 执行全量 `go test -race -count=1 ./...`、`go vet ./...` 和 govulncheck v1.8.0。测试覆盖错误实现、裸退出 1、目标 / 统计伪证据、参数 / 权限 / 超时、PROBE 无域盘写操作、只读 gate、关机启动保护、旧清单与改变域配置、跨领取代际新鲜性。

额外在本机 Docker 的独立 Linux 网桥与 veth / 网络命名空间实测，不使用真实 KVM 宿主：

- iputils 20240905：198.18.0.3 无 ARP / ICMP 回应，结果 FREE；198.18.0.2 有真实 ARP 目标 IP / MAC 应答，结果 IN_USE。
- Thomas arping 2.25：相同 DAD 参数在空闲地址返回 1，成功复现旧误判；新模块拒绝该实现，只得到 ErrIPProbeFailed，无 FREE / IN_USE 状态。
- 指定不存在网桥：实际工具退出 2，新模块返回探测失败，不生成占用结论。

上述 opt-in 测试默认跳过；仅提供专用隔离桥与地址时执行 `TestOptInIPProbeRealBinary`，不默认扫描用户网络。安装包由发布工作流对 Linux amd64 / arm64 分别构建并提供 SHA256SUMS。

### 后端与 PostgreSQL

使用新建本机 PostgreSQL 16 专用库，设置 VMP_TEST_DATABASE_URL，随机 schema 隔离；不连接生产 Agent。完整数据库 `go test -race -count=1 ./...` 实际执行，另对 IPProbe 新用例重复 race 三轮。

覆盖：

- 无证据 / 探测失败不隔离原预留；目标 IP 不匹配和已有域不换地址。
- 单地址可靠解除、仅复核不解除、同 IP 并发及同 claim 结果重放幂等。
- 结果目标 / 宿主 / 身份代次 / 网桥变化、管理员失效、错误探测不解除。
- 无空闲池自动复核，真实占用后推进，FREE 自动接续原 CREATE，预算不重复。
- 重复 retry、取消 / 过期 / 用户失效不重建；CREATE 过期不能继续领取。
- 保留期恢复失败及成功，保留原 IP / 租期 / 截止 / 次数 / 预算，成功才消耗恢复次数。
- 排队超时、单次最大数量、公平批次推进及所有状态字段。
- HTTP 管理员 / 普通用户 / 未登录 / 首登改密 / CSRF 隔离、异步 202 与完整领取 / 回调链。

新 HTTP 测试最初 fixture 漏填宿主非空预算列，曾失败；补齐后单 HTTP、新功能重复三轮与最终完整数据库回归均通过。这是测试数据修正，不以失败输出冒充验收成功。

`go vet`、govulncheck v1.8.0 和差异检查通过。新建本地服务启动自动迁移至 021 / 共 21 条，健康检查通过；不手工挂载 SQL。

### 前端与浏览器

59 项 Node 回归、JavaScript 语法、差异检查通过；覆盖 RBAC、请求布尔值 / 安全头、重复点击、过期会话 / 导航结果、消息 XSS、限批、真实异步文案、搜索 / 中文输入与行焦点保护。

真实静态前端 + 本机控制面 + 专用 PostgreSQL 的 Playwright 验收，任务回调由隔离协议驱动提供，不伪称生产 KVM 已执行：

- 管理员提交安全解除：HTTP 排队后经领取 / 回调，地址由 Q 变 FREE；重复回调仍 200 且无第二次状态副作用。
- 工具错误回调：保持 Q，显示中文错误，允许核查后再次提交。
- 保留期 IP 仍 ALLOCATED 并绑定原实例，网页没有解除按钮；普通用户单 / 批复核接口均 403。
- 轮询更新地址与卡片，搜索仍有焦点；弹窗未提交时不被重绘。
- 真实浏览器发现卡片按钮点击冒泡会立即关闭批量弹窗，统一忽略卡片内交互控件点击后修复；补充真实绑定顺序的按钮 / 子图标冒泡回归，避免仅测试弹窗函数而遗漏入口。
- 1440 桌面及 390 移动页面检查，宽表仅自身横向滚动，不把整个页面撑宽；截图保留在本地 ignored output/playwright。

## 发布与上线边界

镜像工作流发布前重跑测试 / 静态 / 已知漏洞检查，固定版本已存在则拒绝覆盖，推送后验证 Linux amd64 和 arm64 清单；Agent 独立安装包也经测试、vet、漏洞检查后生成。

本轮只发布代码、镜像和 Agent 包，不自动升级 144 / 172 / 170 / 174，不解除任何生产隔离地址、不改外部 DHCP、不运行真实 KVM 创建 / 删除。隔离验证不是对任意生产网桥和虚机的写操作验收；升级后须按 [升级与 IP 恢复](0.5.4升级与IP隔离恢复.md) 在自己的维护窗口验收。

保留 IP 是平台内账本约束，不是外部 DHCP 租约或 ARP 代答。平台整个范围必须从外部 DHCP 动态池排除，ARP 不能代替网络规划，也不能保证探测结束后其他设备永不改用该地址。
