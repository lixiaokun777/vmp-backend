# 0.7.0 发布与升级

配套版本：后端、前端、Agent 均为 `0.7.0`。发布不自动更新任何现网服务器。隔离测试和部署后仍待验证的项目见 [验收清单](0.7.0验收清单.md)。

## 从 0.6.0 升级，最简操作

1. 备份数据库、原 Compose / `.env` 和每台 Agent 的配置、完整状态目录。
2. 确认没有正在执行的创建、删除、镜像同步或密码重置任务。
3. 原数据库、加密密钥、宿主身份与独立令牌全部保留，不重新签发。

在原 `.env` 中仅替换两行固定镜像：

```dotenv
VMP_BACKEND_IMAGE=lixiaokun/vmp-backend:0.7.0
VMP_FRONTEND_IMAGE=lixiaokun/vmp-frontend:0.7.0
```

使用原 Compose 文件、原环境文件、原项目名。在对应部署目录执行；如果平时使用 `-f`，下面命令也必须加上同一组 `-f` 参数：

```bash
docker compose --env-file .env pull control-plane web
docker compose --env-file .env up -d --no-deps control-plane
docker compose --env-file .env logs --tail=100 control-plane
docker compose --env-file .env ps
# 控制面健康后再更新前端。
docker compose --env-file .env up -d --no-deps web
```

后端启动自动执行 `023_instance_metrics_collected_at_idx.sql`，只新增指标清理索引。外置数据库也不需要手工挂载 SQL；数据库账号必须具有建索引和写迁移台账权限。迁移失败会阻止启动，不删除台账、不修改旧迁移绕过校验。建索引可能等待现有事务，按数据库规模安排维护窗口。

前端存在旧静态目录挂载时，应整体更新或取消旧挂载，不能让旧 HTML/JS/CSS 覆盖新镜像。否则换镜像也看不到新功能。

## Agent 升级

从 [Agent v0.7.0](https://github.com/lixiaokun777/vmp-agent/releases/tag/v0.7.0) 下载匹配宿主架构的包和 `SHA256SUMS`，校验后解压到临时目录。

- 每次只升级一台宿主，等待无在途任务，再用原账号执行 `./control.sh stop`。
- 备份原安装目录，替换二进制和配套脚本；保留原 `conf/agent.env`、`AGENT_STATE_DIR`、凭据与任务日志，不能用示例配置覆盖现有配置。
- 用原账号执行 `./control.sh preflight`，通过后 `./control.sh start`。在平台确认心跳、资源预算、镜像与网络就绪，再升级下一台。
- 不修改实例磁盘、存量虚机、网桥、IP 范围或控制台签名密钥。

本版没有新增必填配置，旧的合法配置可继续使用。可选新增项：

| 组件 | 配置 | 默认值 |
| --- | --- | --- |
| 后端、Agent | `LOG_LEVEL` | `info`，允许 debug/info/warn/error |
| Agent | `KVM_INVENTORY_CONCURRENCY` | `4`，允许 1–32 |

Agent 现在对非法数字、布尔值及越界配置启动报错，不再静默回退；若启动失败，按中文错误修正配置，而不是清空状态目录。新增 `HOST_DISK_INSUFFICIENT` 表示创建时实际可用磁盘不足，需先释放安全空间或调整申请，不要降低安全保留额度绕过。

## 更新后检查

- 普通用户和管理员移动导航、申请及改密内联校验、登出、实例任务中文文案正常。
- LDAP 明文连接警告随 StartTLS 切换；建议使用可信证书的 LDAPS/StartTLS。
- 已配置群机器人时，“平台健康告警”开关默认开启；未配置渠道只记日志，不自动启用群通知总开关。
- Agent 日志正常、没有持续 DEGRADED；损坏文件进入私有 quarantine 后需要管理员核查，不把未知任务结果当作已完成。
- 健康告警故障注入及损坏状态注入只在隔离环境进行；不能在生产在途任务上制造故障。

## 回滚

保留原版本镜像与 Agent 包；按原配置回滚组件，不清空数据库、状态目录或实例目录。023 只是新增索引，可保留，不手工改迁移台账。已经迁移缓存引用的宿主回滚旧 Agent 时应暂停缓存 GC 并核查 backing 保护，优先恢复到带完整备份的维护状态；不要在不确认引用关系时人工删缓存。
