## 复跑命令

使用发布工作流固定的 Go 1.27.2。数据库必须是可丢弃的独立测试库，提前在 public schema 安装 pgcrypto；各数据库用例会创建并删除随机命名 schema。不能把生产 DSN 放入 VMP_TEST_DATABASE_URL。

```bash
# 在独立测试库安装扩展（按本地连接参数填写）。
psql "$VMP_TEST_DATABASE_URL" -c 'CREATE EXTENSION IF NOT EXISTS pgcrypto WITH SCHEMA public;'

# 后端仓库，VMP_TEST_DATABASE_URL 非空时才执行数据库回归。
go test -race -count=1 ./...
go vet ./...

# Agent 仓库，所有 KVM 写测试仅针对临时目录与 fake runner。
go test -race -count=1 ./...
go vet ./...

# 前端仓库。
node --check web/mobile-navigation.js
node --check web/app.js
node --check web/notifications.js
node --test tests/*.test.js
node tests/browser-fixture.js
```

前端浏览器截图位于本地 `vmp-frontend/output/playwright/070-*.png`（不提交 Git）。桌面对比的两个文件 `070-desktop-baseline.png` / `070-desktop-current.png` SHA-256 相同：`238a0dc9a088caa0ce6de4260888c4895c38d228598c5e15b69e936e75e6a567`。这是同一隔离数据下资源总览布局的一致性验证，不代表所有页面完全无内容变化。

## 部署后验收与约束

- 确认控制面自动迁移总数 23，原数据库和宿主身份继续使用，前后端/Agent 均来自同一候选分支。
- 在 174 环境验证管理员/普通用户手机导航、非法与合法申请、修改密码、LDAP 警告及任务中文展示。
- 健康告警先接入测试群/本地机器人，再故障注入，核对三轮阈值、同类 30 分钟节流、总开关和事件开关。数据库断开期间只能记日志，发送链路恢复后才能送达。
- 损坏文件注入只用于已停机、无任务的隔离 Agent 状态副本，验证隔离文件及 state-file 检查；不要损坏现网 credentials.json 或在途任务日志。
- 缓存 GC 在磁盘压力下执行，并保留当前目录镜像/其他有效引用/人工保护。新旧引用来源不确定时拒绝回收，不手工删除在用 backing 文件。
- 没有新增业务功能；未改已有任务字段语义，只新增磁盘不足错误码；数据库只新增 023 索引；IP 探测/隔离和控制台票据/鉴权流程未调整。
