## 任务确认与安全恢复

领取 `/api/v1/agents/{host}/tasks/next` 返回 `claim_token` 和 `lease_until`；同宿主最多一个 RUNNING。Agent 每十秒续租，60 秒租约到期/旧代际返回 409。结果请求也带令牌，但令牌不写任务历史。回执仅存 task/host、令牌摘要、结果摘要和时间。

同代际同结果重复确认成功且不重复扣账；冲突结果/失效代际拒绝。删除清表后回执仍能确认。可安全幂等任务过期重排，受三次尝试上限约束；REBOOT 租约过期或 EXECUTION_UNCERTAIN 直接失败，核查后手动操作，不盲重启。

Agent 私有状态目录含领取/结果日志、凭据、进程锁。确认失败先重发，不先领下一任务。旧成功结果按任务及负载独立缓存，重新领取相同负载只换令牌重发；换 IP 等负载变化不可复用。缓存最多 256 条，满时保留当前结果并停止领取。回执保留 60 天，窗口外且任务已清表的缓存需人工逐项核查，不静默淘汰，不承诺任意故障下无限期 exactly-once。

创建回滚失败、工作取消或租约丢失保现场；下一有效执行者验证补偿标记、清单、域 UUID/metadata 才可补偿。不对外部域自动销毁或删盘。

## 租期

自然到期的初次实例截止为原 `expires_at + 7 天`，不是每次调和再延长七天。RUNNING 排停机，STOPPED 直接保留。平台停机太久、截止已过则排删除，仍等宿主确认才释放 IP/预算。

恢复次数用完再次到期/释放直接排删除；旧版本已经错误进入第二次 RETAINED 的实例也由新调和器保守排删除，原 IP/预算仍等宿主确认才释放。过渡状态等待关联任务收敛；ERROR 保留现场供排障、重试或明确立即删除，不因一次失败自动丢盘。回收任务最终失败后保留错误和资源，需核查后显式重试。

## 017/018 升级

只追加迁移，不修改已发布的 001-016 与 checksum。升级前备份数据库、Agent 配置和状态；暂停新增调度，核查并停止旧 Agent 在途任务。

- 017：实例快照、租约、确认回执；旧快照优先取 CREATE_INSTANCE 负载并重算宿主账。`allocation_snapshot_source=FLAVOR_FALLBACK` 表示原创建数据缺失，只能用当前规格兜底；恢复调度前核对 libvirt/磁盘、修正实际快照并重算预算，不能声称未知历史资源已准确恢复。
- 旧 PROCESSING 保守转 FAILED、标记 execution_uncertain，禁止直接重提或自动重放；管理员核查实例/任务/审计后处理。新审批不再产生跨事务 PROCESSING。
- 018：LDAP 目录标志、独立宿主身份；旧宿主暂停调度，按 [身份与凭据加固](身份与凭据加固.md) 逐台签发、导入、验证新心跳后恢复。不重建原 VM。
- 后端、前端（含 Nginx CSP）、Agent 必须配套。旧 Agent 不支持领取租约和独立身份，不能混用。禁止新旧进程共用状态目录或重新开启共享 token 回滚。

## 回归命令

仅使用专用测试数据库，先在 public 初始化 pgcrypto，避免临时 schema 清理移除扩展：

```bash
psql "$VMP_TEST_DATABASE_URL" -c 'CREATE EXTENSION IF NOT EXISTS pgcrypto WITH SCHEMA public;'
go test -race -count=1 ./...
go vet ./...
```

测试创建随机 reliability_test_*、identity_test_* 等 schema 并清理自身；未设 DSN 会跳过。发布 CI 提供独立 PostgreSQL 和 DSN，不把跳过当完整通过。Agent 用临时目录/假 Runner，LDAP 和机器人用本机假服务，均不操作真实宿主或企业目录。

前端运行 `node --test tests/frontend.test.js` 和三份第一方 JS 语法检查；Nginx 用 nginx -t、浏览器验证安全头与登录/退出/角色切换。真实 KVM 验收仍需专用宿主验证创建、电源、续期/审批、保留/恢复、删除及 Agent 中断。模拟回归不等于现网全部主机验收，本轮没有操作 172 存量虚机。
