# 数据库说明

`001_init.sql` 建立宿主机、规格、镜像、申请、实例、任务和审计日志。`002_ipam.sql` 增加网络与 IP 资源池。`003_kvm_inventory.sql` 增加宿主机事实和存量 KVM 域发现。`004_agent_provisioning_contract.sql` 为镜像增加宿主机文件名和安全格式约束，用于 Agent 精确定位只读基础镜像。

数据库中不增加明文密码字段。初始密码在申请事务内生成，明文只进入当次 HTTP 响应；任务 JSON 仅保存 `pgcrypto` 产生的 bcrypt 摘要。

迁移文件只能追加，已执行的迁移禁止原地修改。表结构变更必须在同一次提交中更新架构和 API 文档。
