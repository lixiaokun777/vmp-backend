# 数据库说明

`001_init.sql` 建立宿主机、规格、镜像、申请、实例、任务和审计日志。`002_ipam.sql` 增加网络与 IP 资源池表，新安装默认不创建示例网络。`003_kvm_inventory.sql` 增加宿主机事实和存量 KVM 域发现。`004_agent_provisioning_contract.sql` 为镜像增加宿主机文件名和安全格式约束。`005_reconcile_node3_image_inventory.sql` 将 Ubuntu 22.04 映射到 node3 上的实际文件名，并在 Ubuntu 24.04 文件补齐前停用该镜像。`006_instance_lifecycle.sql` 增加到期与保留期扫描索引。`007_admin_resource_management.sql` 增加 Agent 安全上限、Web 调度配额和镜像来源字段，不修改已有网络数据。`008_task_success_cleanup.sql` 清理已最终成功任务在早期尝试中留下的错误文本。

宿主机 `agent_allocatable_*` 是 Agent 上报的安全上限，`quota_*` 是管理员配置，`allocatable_*` 保存两者的较小值并供调度器使用。

`instances.expires_at` 表示租期截止时间，`retention_until` 表示关机后的数据保留截止时间。实例删除成功后，会在同一事务内释放 IP 和宿主机 CPU、内存、磁盘配额，并清除对应的实例、申请和任务；审计记录不随业务记录删除。

`ip_addresses` 只保存各网络当前有效起止范围内的地址。网络范围修改会锁定该网络的地址记录，拒绝移除任何非空闲地址，并以事务方式删除范围外空闲地址、补齐范围内地址。

`009_auth_rbac.sql` 增加 `users` 和 `user_sessions`。本地密码使用 PostgreSQL `pgcrypto` 的 bcrypt 哈希，LDAP 用户只保存目录 DN 和同步属性，不保存 LDAP 密码。会话表只保存随机令牌的 SHA-256 摘要，并在用户停用、删除或密码重置时清理。

`010_ldap_settings.sql` 增加单例 `ldap_settings` 配置表。LDAP 绑定密码只保存 AES-GCM 密文，加密密钥来自运行环境的 `SETTINGS_ENCRYPTION_KEY`，不写入数据库。

`011_audit_console.sql` 为 `audit_logs` 增加执行结果、来源 IP、User-Agent 和请求 ID，并为时间、操作人、动作和资源增加查询索引。审计记录是独立合规证据，不对实例设置级联删除。

`012_console_session_replay.sql` 增加控制台会话核销表，通过 `used_at` 原子更新阻止同一票据重放。

数据库中不增加明文密码字段。初始密码在申请事务内生成，明文只进入当次 HTTP 响应；任务 JSON 仅保存 `pgcrypto` 产生的 bcrypt 摘要。

迁移文件只能追加，已执行的迁移禁止原地修改。表结构变更必须在同一次提交中更新架构和 API 文档。
