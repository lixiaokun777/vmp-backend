# 数据库说明

`001_init.sql` 建立宿主机、规格、镜像、申请、实例、任务和审计日志。`002_ipam.sql` 增加网络与 IP 资源池表，新安装默认不创建示例网络。`003_kvm_inventory.sql` 增加宿主机事实和存量 KVM 域发现。`004_agent_provisioning_contract.sql` 为镜像增加宿主机文件名和安全格式约束。`005_reconcile_node3_image_inventory.sql` 将 Ubuntu 22.04 映射到 node3 上的实际文件名，并在 Ubuntu 24.04 文件补齐前停用该镜像。`006_instance_lifecycle.sql` 增加到期与保留期扫描索引。`007_admin_resource_management.sql` 增加 Agent 安全上限、Web 调度配额和镜像来源字段，不修改已有网络数据。

宿主机 `agent_allocatable_*` 是 Agent 上报的安全上限，`quota_*` 是管理员配置，`allocatable_*` 保存两者的较小值并供调度器使用。

`instances.expires_at` 表示租期截止时间，`retention_until` 表示关机后的数据保留截止时间。实例删除成功后，会在同一事务内释放 IP 和宿主机 CPU、内存、磁盘配额。

数据库中不增加明文密码字段。初始密码在申请事务内生成，明文只进入当次 HTTP 响应；任务 JSON 仅保存 `pgcrypto` 产生的 bcrypt 摘要。

迁移文件只能追加，已执行的迁移禁止原地修改。表结构变更必须在同一次提交中更新架构和 API 文档。
