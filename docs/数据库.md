# 数据库说明

0.5.0 自动迁移至 `020`。`019_resource_readiness.sql` 增加固定总预算来源、实时安全余量、按宿主镜像/网络就绪矩阵、镜像代次、实例网络关联与保守域观察。旧宿主 `budget_source=LEGACY` 不能继续接新申请，须升级配套 Agent 并上报完整新协议；既有实例、IP 与磁盘不会因此被删除。

`020_platform_governance.sql` 增加平台配额/租期/保留策略、用户授权的有限自动续期、审批代理与分配、压缩历史归档及行摘要、平台事件通知持久队列和宿主故障边沿状态。默认额度不限、自动续期关闭、历史永久保留。审批/交付失败与宿主通知受已有通知总开关控制，不自动开启群发。

`017_reliable_execution.sql` 新增分配快照/来源、任务令牌/租约、独立摘要确认回执并重算资源台账。FLAVOR_FALLBACK 需核对实际资源，旧不确定 PROCESSING 标记 FAILED 后禁止盲重提。

`018_identity_hardening.sql` 新增 LDAP 目录存在标志及 host_credentials，平台停用独立保留，运行令牌只保存宿主专属 SHA-256；旧宿主需签发后恢复调度。详见 [P1 修复与验收](P1修复与验收.md) 与 [身份升级](身份与凭据加固.md)。

016_login_protection.sql 新增 login_attempt_buckets：哈希维度键、预占尝试次数、窗口到期时间。限制跨控制面副本共享，原子更新防并发绕过；过期一天的记录由后台分批清理。无需 Redis。

控制面通过 Go `embed` 把 `migrations/*.sql` 编译进二进制，连接数据库后、HTTP 服务启动前自动执行迁移。`schema_migrations` 记录文件名、SHA-256 和执行时间；PostgreSQL advisory lock 确保多个控制面副本不会并发迁移。每个迁移单独使用事务，任何一个失败都会使控制面拒绝启动。

新安装、已有 PostgreSQL 和从旧版升级都使用同一套启动流程，不再向 `/docker-entrypoint-initdb.d` 挂载 SQL。`001_init.sql` 已改为幂等初始化，用于在首次建立迁移台账时安全接管旧数据库，不会覆盖管理员已修改的默认规格或镜像。

`001_init.sql` 建立宿主机、规格、镜像、申请、实例、任务和审计日志。`002_ipam.sql` 增加网络与 IP 资源池表，新安装默认不创建示例网络。`003_kvm_inventory.sql` 增加宿主机事实和存量 KVM 域发现。`004_agent_provisioning_contract.sql` 为镜像增加宿主机文件名和安全格式约束。`005_reconcile_node3_image_inventory.sql` 统一 Ubuntu 镜像文件名，并在 Ubuntu 24.04 文件补齐前停用该镜像。`006_instance_lifecycle.sql` 增加到期与保留期扫描索引。`007_admin_resource_management.sql` 增加 Agent 安全上限、Web 调度配额和镜像来源字段，不修改已有网络数据。`008_task_success_cleanup.sql` 清理已最终成功任务在早期尝试中留下的错误文本。

宿主机 `agent_allocatable_*` 是 Agent 上报的固定平台预算，`quota_*` 是管理员配置，`allocatable_*` 保存两者的较小值；`reserved_*` 是实例分配快照的总预留。`safe_available_memory_mb` / `safe_available_disk_gb` 则表示测量时的实际新增安全余量，不再当作总预算后扣一遍预留。调度必须同时通过预算剩余、实时安全余量、独立身份及当前镜像/网桥就绪门槛。

`instances.expires_at` 表示租期截止，`retention_until` 表示保留截止（自然到期为原截止 + 七天）。实例删除确认后同事务释放 IP、按分配快照扣配额，清除实例/申请/任务；审计与摘要确认回执不随之删除。恢复过的实例不再享受第二次七天保留。

`ip_addresses` 只保存各网络当前有效起止范围内的地址。网络范围修改会锁定该网络的地址记录，拒绝移除任何非空闲地址，并以事务方式删除范围外空闲地址、补齐范围内地址。

`009_auth_rbac.sql` 增加 `users` 和 `user_sessions`。本地密码使用 PostgreSQL `pgcrypto` 的 bcrypt 哈希，LDAP 用户只保存目录 DN 和同步属性，不保存 LDAP 密码。会话表只保存随机令牌的 SHA-256 摘要，并在用户停用、删除或密码重置时清理。

`010_ldap_settings.sql` 增加单例 `ldap_settings` 配置表。LDAP 绑定密码只保存 AES-GCM 密文，加密密钥来自运行环境的 `SETTINGS_ENCRYPTION_KEY`，不写入数据库。

`011_audit_console.sql` 为 `audit_logs` 增加执行结果、来源 IP、User-Agent 和请求 ID，并为时间、操作人、动作和资源增加查询索引。审计记录是独立合规证据，不对实例设置级联删除。

`012_console_session_replay.sql` 增加控制台会话核销表，通过 `used_at` 原子更新阻止同一票据重放。

`013_lease_approvals.sql` 增加 `approval_requests`，保存超过 7 天的创建、续期和保留期恢复申请、审批意见及执行结果。待审批记录不创建实例、不预留 IP，也不占用宿主机配额。

`014_approval_workflow_hardening.sql` 为审批增加 24 小时截止时间和超时、撤回、已批准但执行失败状态，为实例增加最多一次的 `restore_count` 恢复计数。

`015_group_notifications.sql` 增加 `notification_settings` 加密配置表和 `notification_events` 持久化发送队列表。同一实例、阶段、目标时间唯一，记录尝试次数、重试时间、结果与正文，不保存机器人明文凭据。

数据库中不增加明文密码字段。初始密码在申请事务内生成，明文只进入当次 HTTP 响应；任务 JSON 仅保存 `pgcrypto` 产生的 bcrypt 摘要。

迁移文件只能追加，从 `0.4.1` 起已记入 `schema_migrations` 的迁移禁止原地修改，否则校验值检查会阻止控制面启动。表结构变更必须在同一次提交中更新架构和 API 文档。
