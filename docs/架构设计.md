# 后端架构设计

本轮加固与升级边界见 [P1 修复与验收](P1修复与验收.md)。审批与资源变更原子提交，Agent 采用宿主独立身份、领取租约和确认回执，旧共享协议不能混用。

0.5.1 增加 [P2 可靠性与治理](P2功能与验收.md)。固定总预算与实时新增安全余量分开，资源只按快照预留一次；宿主独立身份、新鲜镜像代次/摘要和网桥就绪矩阵共同决定调度。旧预算报告保持不可调度，不能把网页“启用”当作真实镜像可交付。

## 群机器人通知

控制面内置每分钟运行的通知调度器，从真实租期和保留期生成事件。`notification_settings` 保存加密地址和规则，`notification_events` 使用实例、阶段、目标时间去重；发送前核对并共享锁定本轮实例，续期或删除会使旧事件取消。多副本使用数据库 advisory lock 串行发送，失败最多尝试五次，消息合并并受频率及长度限制。通知失败不改变虚拟机生命周期。完整规则和 HTTP 投递边界见 [群通知](群通知.md)。

## 职责边界

控制面保存期望状态、执行调度和租期规则，Agent 负责宿主机现场状态与虚拟化操作。两者通过 JSON 协议通信，不共享 Go 内部包；跨任务租约、身份及资源就绪协议版本必须配套升级，本次统一为 0.5.1，不允许混用旧协议。

## 核心流程

1. 用户提交固定规格、镜像、网络和租期；不超过 7 天直接执行，超过 7 天先生成审批单。
2. 自动申请或管理员批准后，数据库事务内检查用户配额并锁定资源，选择满足预算、安全余量、镜像/网络就绪的宿主并预留 IP；待审批阶段不占用资源。
3. 生成一次性密码，由 `pgcrypto` 生成摘要，再构建幂等 `CREATE_INSTANCE` 任务。
4. Agent 串行领取 60 秒任务租约，持久化领取/结果、十秒续租；心跳独立。确认丢失重发结果，超时保守恢复，重启不确定不盲重放。
5. Agent 在写入磁盘前结合 ARP 与 ICMP 探测预留 IP；如果已占用，控制面隔离冲突地址、预留下一个空闲地址并更新原任务重试。池耗尽后补池重试会重新建立缺失预留。
6. 控制面更新实例、IP 和任务状态；Guest Agent、目标 MAC 和网络可用性独立报告交付状态，不以 ICMP 单项决定删盘。完整域扫描保守修正稳定电源状态，缺失连续确认仍保留资源，禁止因一次扫描失败误删。
7. 用户可下发电源、改密、续期和恢复；超过七天先审批，审批行锁、实际 DB 变更、任务和批准结果同事务，不留下跨事务 PROCESSING。
8. 十五秒调和覆盖 RUNNING/STOPPED；原到期 + 七天排删除，恢复过的实例直接排删除。确认成功才按分配快照释放 IP/预算，清除业务记录但保留摘要回执。
9. 自动回收任务连续失败达到上限后停止重新生成，避免对故障宿主机无限重试。
10. 管理员通过服务器分页的审计/审批/用户/实例查询；审计与删除业务对象解耦。默认永久保留，显式归档、下载校验、精确 ID/行摘要保护后才清理。
11. 打开控制台时校验归属、租期和新鲜实际托管域，签发五分钟一次性票据。浏览器连平台同源桥，控制面固定拨号宿主纳管 IP，Agent 原子核销后只代理本机回环 VNC 或托管串口。创建中/错误状态保留现场可诊断，不接管外部域。
12. 审批默认 24 小时有效；代理与转交协助路由，重复批准只执行一次。批准后交付失败回写审批并入平台事件通知队列。用户主动授权的自动续期受次数、单次小时和总期限约束，不绕过长租期审批。

## 安全边界

- 浏览器通过 HttpOnly、SameSite=Strict Cookie 建立服务端会话，客户端传入的用户名不会作为身份依据。
- 管理员拥有平台管理权限；普通用户只能申请虚拟机并访问申请人为自己的实例。
- 平台账号与 LDAP 账号使用独立登录类型，后端同时校验用户来源。
- 本地密码保存 bcrypt 哈希；LDAP 先按当前登录规则查唯一 DN 再绑定用户密码；平台停用与目录状态分别检查，不保存目录用户密码。
- LDAP 服务账号密码使用 AES-GCM 加密，密钥与数据库分离保存。
- `kvm-readonly` 主机状态始终为隔离或降级，不会被调度。
- Agent 引导凭据仅纳管新宿主；已有宿主凭独立随机运行令牌，所有 Agent 路径绑定 host ID，可单独轮换/吊销，无共享运行值回退。
- Cookie 写操作要求 X-VMP-Request 安全头，前端动态字段按上下文编码并配套同源脚本 CSP。
- 调度、IP 预留、实例和任务创建使用串行化事务。
- 存量域只进入发现表，不自动变成平台托管实例。
- 新注册的 KVM 宿主机无论是只读还是写模式，初始状态均为 `CORDONED`，必须手工恢复调度。
- 明文初始密码不持久化，不写入任务或审计日志。
- 重置实例密码时同样只在当前响应返回明文，任务仅携带 crypt 摘要，并由 QEMU Guest Agent 在虚机内应用。
- 宿主总预算取 Agent 固定预算与管理员配额的较小值，再扣分配快照预留；实时新增安全余量只作为另一道门槛，不重复扣预留。Web 无法绕过 Agent 预算和现场安全余量。
- 网络和唯一有效的 IP 起止范围由管理员在同一个配置中显式定义；修改范围只移除旧的空闲地址，范围外存在占用地址时拒绝修改。Agent 在任何虚拟化写操作前复检 IP 是否已被占用。
- 远程镜像在校验和同步完成前不允许启用。
- VNC 仍由 libvirt 监听在 `127.0.0.1`，浏览器仅连平台同源 WebSocket，Agent 代理仅控制节点可达；票据用 HMAC-SHA256 绑定宿主、实例、账号、模式和过期时间。会话期间定期复核账号授权与租期，连接/消息大小有上限。
