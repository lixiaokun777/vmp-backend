# 资源就绪、交付与服务器分页

## 资源预算不是实时剩余量

宿主 `allocatable_*` 是管理员配额与 Agent 总预算的较小值，`reserved_*` 是平台已分配实例快照总占用，保留期和失败待清理实例也继续占用。Agent 必须报告 `budget_source=CONFIGURED_TOTAL`、实际测量时刻 `resource_measured_at` 和 `safe_available_memory_mb/disk_gb`。旧协议或测量超过120秒的宿主不参与新调度，不能假装全池已就绪。

调度同时检查“预算－平台预留”和实时安全余量。后者仅额外扣除测量之后的分配、尚未被本次完整域扫描确认的在途创建/启动，不再次扣掉全部在用 reserved。重复发送旧测量不能补回已预占的余量；乱序的更旧测量不覆盖新预算和清单。

## 镜像与网络按宿主就绪

- 独立凭据访问 `GET /api/v1/agents/{host_id}/catalog`，返回全镜像定义（含generation、checksum、file_name、source_type、source_location）和网络定义。只有 Agent 可以读取自己的目录，不回显给普通用户。
- 心跳 facts.images 项为 `{image_id,generation,file_name,checksum,status,error}`，facts.networks为 `{bridge,ready,error}`，`readiness_complete=true` 才说明目录探测完整。镜像必须匹配当前代次、文件名和摘要，网络必须匹配实际可用网桥；120秒未更新为陈旧。
- 修改镜像的文件、位置、来源或摘要会增加 generation，原host就绪记录失效；仅重命名不会改变已有文件。旧代次同步结果不能启用新定义。
- 创建只选择ACTIVE、写模式KVM、预算/安全余量足够且当前镜像/网络就绪的宿主，不再假定每台宿主都拥有同一模板和网桥。

### 远程 / OSS 镜像

管理员提供HTTPS地址、64位SHA-256和安全file_name，禁止地址userinfo用户名密码。Agent还需配置允许下载域名；私有OSS按Agent文档配置明确私网白名单，不开放loopback/link-local或任意内网。地址可带短时签名查询参数，不得打印到日志、群聊或公开页面。

管理员显式选择1至128台写模式宿主，调用 `POST /api/v1/images/{image_id}/sync`，请求 `{host_ids:[...]}`；空列表不隐式同步全池。服务端按宿主/镜像/代次生成幂等SYNC_IMAGE任务，重复点击不会产生并发下载。任务负载包含image_id/source_url/checksum/file_name/image_generation；结果须匹配同一代次和摘要。

下载、摘要验证和原子发布由Agent执行。缓存是不可变内容寻址路径 `.vmp-cache/<sha256>/<file_name>`，不覆盖本地模板或在用backing。创建负载携带 `image_checksum`、`image_generation`；本地未全局指定摘要时使用目标宿主实际探测摘要。创建前Agent再次核验打开的文件。

`GET /images?all=1` 返回 generation、desired_enabled及host_readiness。desired_enabled表达管理员希望启用；远程enabled只有至少一台当前代次实际READY时才生效。可用不表示所有宿主可用，具体调度仍按矩阵判断。同步失败不改变任何实例/VM状态。

## 分层交付与保守对账

实例有两个独立状态：lifecycle_status表达生命周期，delivery_status表达交付。QUEUED→CREATING→域启动后生命周期RUNNING，但交付可能仍为NETWORK_PENDING或GUEST_PENDING；只有网络、Guest Agent/cloud-init等真实证据达到约定条件才为READY。UNKNOWN仅用于历史未核验实例，不能把ping通当成完整交付。

创建时域已正常运行但网络未就绪，不以一次ping超时自动回滚删域/删盘。详情返回delivery_message、observed_domain_status、last_domain_seen_at、console_available。未READY的新交付实例暂时拒绝重置密码，避免cloud-init后续覆盖重置；历史UNKNOWN保持兼容并由Agent复核。

完整且新测量的心跳可修正稳定RUNNING/STOPPED电源状态，但不覆盖执行中的任务、不延长租期、不自动恢复保留期。一次漏报或不完整扫描不释放资源；连续三次不同完整扫描且跨至少30秒仍未找到域，仅标MISSING/DEGRADED告警，原IP/预算/记录保留。实际扫描周期较长时等待也会更长。

地址池全部占用导致创建失败后，扩容IP池再重试，会在同一事务恢复IP预留、实例IP和执行负载后再复位原任务，不重复记账。已有托管域而IP关系缺失、或原执行结果不确定时拒绝盲目重建，要求先救援核查。

### 异常救援控制台

未到期、实际存在且新鲜确认的本平台托管域，可在RUNNING/PROVISIONING/ERROR/STOPPED生命周期签发控制台；允许实际运行/暂停等可诊断域，不对外部域开放。它不会自动开机或创建域。票据最长5分钟且不超实例期限，连接时再次检查授权、域、期限、状态并一次性核销。保留/释放/删除中拒绝。浏览器通过同源WebSocket桥接，不直接访问宿主控制台端口。

## 服务器分页接口

四类返回统一 `{items,total,page,page_size}`，默认page=1、page_size=20，上限100；越界页码夹到最后有效页，空数据为page=1。总数和记录取同一只读数据库快照，筛选均参数化。普通用户作用域始终由服务端身份限定，scope=all不能越权。

| 接口 | 额外参数 / 枚举 |
| --- | --- |
| GET /users | keyword用户名/显示名/邮箱；role=ADMIN/USER；source=LOCAL/LDAP；status=ENABLED/DISABLED/DIRECTORY_UNAVAILABLE/MUST_CHANGE_PASSWORD |
| GET /instances | scope=mine；keyword实例名/所有者/IP；host_id；status=PROVISIONING/RUNNING/STOPPED/STOPPING/STARTING/REBOOTING/RETAINED/DELETING/ERROR/RELEASED（已删除不展示） |
| GET /approvals | scope=mine；keyword申请号/申请人/实例/原因；type=CREATE/RENEW/RESTORE；status=PENDING/PROCESSING/APPROVED/APPROVED_FAILED/REJECTED/EXPIRED/WITHDRAWN/FAILED |
| GET /ip-addresses | 必填network_id；keyword地址/实例/所有者；status=FREE/ALLOCATED/RESERVED/QUARANTINED |

未提供或ALL表示全部。非法枚举/标识返回422。IP项直接返回owner、lifecycle_status、allocated_at/reserved_at，不在前端用当前页实例猜归属；超过512的地址也能逐页查看。

实例响应额外返回 `expiring_total`，按完整授权scope统计未来24小时RUNNING/STOPPED/STARTING/REBOOTING实例，不受当前页、keyword或status筛选影响。管理员flavors响应有 usage 聚合（running/retained/active/memory_mb/disk_gb/percent），按flavor_id与分配快照计算，不使用本页切片或同名规格猜总占用。hosts用于少量宿主筛选，仍为完整列表。

## 本地应急管理员与LDAP

用户变更、删除和LDAP同步使用同一事务advisory锁，变更时重验操作者权限，同事务保留至少一个enabled LOCAL ADMIN。两管理员并发互相停用不会清空管理员；LDAP不能取代本地应急账号。用户有活动实例或待处理审批不能删除，删除与创建共享用户额度事务锁。

没有本地应急管理员的旧环境启动时，必须提供新且未占用的BOOTSTRAP_ADMIN_USERNAME和强密码；初始化不会提升、复用或重新启用旧账号。成功创建后强制首登改密；存在正常本地管理员时不覆盖密码。LDAP同步真正按500条分页，只有所有页查询成功才事务提交；目录移除不改变本地应急用户。
