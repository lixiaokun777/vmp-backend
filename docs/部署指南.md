# VMP 部署文档入口

0.8.0 可选宿主调度及删除修复升级说明见 **[0.8.0 发布与升级](0.8.0发布与升级.md)**：先后端自动 024 迁移，再前端，最后逐台 Agent 0.7.3。没有新增必填配置，不自动升级服务器。

第一次部署，请阅读 **[从零部署和日常运维手册](新手部署手册.md)**。这是一份完整、逐步执行的主手册，每条操作都区分控制节点、KVM 宿主机和浏览器。

当前推荐组件：

| 组件 | 版本 | 部署方式 |
| --- | --- | --- |
| 后端 | 0.8.0 | Docker 镜像 |
| 前端 | 0.8.0 | Docker 镜像，Nginx |
| Agent | 0.7.3 | 每台宿主的 Go 安装包和 control.sh |

三个组件版本号不同，按上表配套，不要把 Agent 包名误写成 0.8.0。

已有环境阅读 **[0.8.0 发布与升级](0.8.0发布与升级.md)**。没有新增必填配置，不清空数据库、Agent 状态或虚机磁盘，也不重新签发已有独立宿主身份。0.4.x 共享令牌环境仍须完成身份迁移。

## 重要提醒

- 内置和外置数据库二选一；外置数据库只使用对应 Compose，不叠加内置模板。
- SQL 已编译进后端，启动时自动迁移，无需手工挂载初始化目录。
- 不清空数据库卷、Agent state 或实例磁盘来排障。
- 新宿主先只读；已运行的宿主升级保留原 host ID、账号、凭据、目录和资源预算。
- 密码、令牌、加密密钥各自不同；加密密钥不能升级时重新生成。
- 原本本页的安装步骤已统一合并进主手册，避免两份流程相互矛盾。
