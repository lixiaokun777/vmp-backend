# VMP 部署文档入口

第一次部署，请阅读 **[从零部署和日常运维手册](新手部署手册.md)**。这是一份完整、逐步执行的主手册，每条操作都区分控制节点、KVM 宿主机和浏览器。

当前推荐组件：

| 组件 | 版本 | 部署方式 |
| --- | --- | --- |
| 后端 | 0.5.5 | Docker 镜像 |
| 前端 | 0.5.3 | Docker 镜像，Nginx |
| Agent | 0.5.4 | 每台宿主的 Go 安装包和 control.sh |

版本号不同是正常的配套修补组合，不需要换回旧 Agent。

已部署后端 0.5.4 / 前端 0.5.3 / Agent 0.5.4 的环境，阅读 **[0.5.5 修复与升级](0.5.5修复与升级.md)**：本次只更新后端镜像，无新迁移或配置。更早环境尚未完成 IP 探测升级的，仍按 **[0.5.4 升级与 IP 隔离恢复](0.5.4升级与IP隔离恢复.md)** 更新必要组件；更换 iputils-arping 不会自动清除历史隔离状态。

## 重要提醒

- 内置和外置数据库二选一；外置数据库只使用对应 Compose，不叠加内置模板。
- SQL 已编译进后端，启动时自动迁移，无需手工挂载初始化目录。
- 不清空数据库卷、Agent state 或实例磁盘来排障。
- 新宿主先只读；已运行的宿主升级保留原 host ID、账号、凭据、目录和资源预算。
- 密码、令牌、加密密钥各自不同；加密密钥不能升级时重新生成。
- 原本本页的安装步骤已统一合并进主手册，避免两份流程相互矛盾。
