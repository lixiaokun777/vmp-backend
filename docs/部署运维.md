# 部署运维

首次安装和外置 PostgreSQL 请先阅读 [从零部署和日常运维手册](新手部署手册.md)。当前推荐后端 0.5.3、前端 0.5.2、Agent 0.5.3，沿用 0.5.1 的身份、预算和就绪协议；版本号不同不等于不兼容。功能边界见 [P2 功能与验收](P2功能与验收.md)。

本轮仅增加宿主凭据列表元数据和网页签发入口，无新迁移或配置项。已有正常独立身份升级无需重新签发，Agent 0.5.3 不重装；旧 0.4.x 共享身份迁移仍按主手册完整执行。

## 发布前检查

1. 备份 PostgreSQL、加密/签名密钥、Agent 配置和受控状态目录；仅数据库备份不能恢复虚拟机磁盘。确认恢复演练可用。
2. 替换示例引导令牌及密钥。每宿主运行凭据独立签发；不再使用后端共享运行令牌。至少保留一个本地应急管理员。
3. 全新与已有数据库都由后端启动自动执行内置迁移，0.5.1 到 `020`，不得手工重跑 SQL。失败拒绝服务，先排查权限、历史摘要和日志，不能删除迁移台账绕过。
4. 暂停新调度，等待执行中任务结束，依次更新控制面/前端和各宿主 Agent。不在宿主旧 Agent 未停止时同时启动新版；Agent 不用 systemd，按受控账号执行 `./control.sh stop/start/status`。
5. 升级到独立身份时按 [身份与凭据加固](身份与凭据加固.md) 给旧宿主分别轮换并导入凭据。确认新心跳总预算、安全余量及镜像/网桥就绪矩阵后再放开调度。
6. 本地镜像必须在受限镜像根中，经真实路径和受保护缓存检查；远程镜像须明确允许来源、SHA-256 校验、对目标宿主同步成功。不得删除被 overlay 引用的内容寻址缓存。
7. 网络与正式 IPAM/DHCP 协调；确认专用范围、网桥、ARP 权限和 DNS。不能仅以 ping 不响应认定空闲，也不能仅以 ping 超时删除实例。
8. 使用发布镜像在专用 PostgreSQL 做迁移、登录、RBAC、CSRF、分页、配额并发和 Agent 协议验收；无 DB 配置而跳过集成测试不算通过。
9. 公网访问必须启用 HTTPS、Secure Cookie 和可信代理限制。核对通知总开关/机器人以及新审批、失败、宿主事件开关，不将真实测试消息大量发到生产群。

## 控制台与救援

浏览器只连接平台同源 `/api/v1/console/vnc` 或 `/api/v1/console/serial`，HTTPS 入口转为 WSS；控制面内部再连接受信任的 Agent 运行时。后端固定拨号宿主纳管 IP，`CONSOLE_PUBLIC_URL` 用于提供端口、路径和 TLS 名称，不支持指向其他 IP 的外部代理。不要把 Agent 19090 端口开放到公网。`CONSOLE_SIGNING_KEY` 至少 32 字节随机值并在控制面与 Agent 一致，票据五分钟有效、单次核销。

控制面每进程最多 64 个桥接连接、每账号最多 4 个，单条消息最多 2 MiB。连接期间每 30 秒重新检查登录/角色/目录/宿主凭据与实例租期，登出、停用、吊销或释放会终止连接；最长单次连接 24 小时。这是每副本保护而非分布式全局并发限额。

实例所有者或管理员可对真实存在且受平台标记约束的托管域打开救援控制台，包括创建中或错误现场。不提供外部 VM 接管，不因救援延长租期，不通过控制台偷偷启动已释放域。无域/已过期/保留期等场景按实际权限和生命周期拒绝。

## 回收与对账

控制面先下发到期关机，保留原磁盘、IP 和配额七天后删除。强制删除跳过保留；恢复一次后的实例不再获取第二次保留。关机失败需检查任务，不能在未确认关机时假报进入保留期。

宿主手工电源操作仅在完整成功扫描、匹配托管实例、没有冲突任务时修正观察与稳定电源状态。缺失域须连续确认，仍不自动删除账本、IP 或磁盘。单次扫描失败不构成删除依据。异常现场可用控制台排查；镜像/地址池修复后通过实例重试重新检查 IP 预留。

## 公平使用、审批和通知

平台策略默认兼容原租期规则：单次超过 168 小时需要审批。可设置每用户实例/CPU/内存/磁盘、未来租期与连续总占用上限；0 表示不限。自动续期需管理员开启、用户主动授权，受小时数、次数和期限共同限制，反复开关不能清零次数。

管理员可设置不超过 90 天的代理或手工转交 pending 单据；其他管理员仍可应急处理。群通知使用有限事件队列与失败退避，健康心跳不刷屏。消息没有凭据，但不是严格一次投递，机器人响应丢失时可能重复。

## 审计、归档与回滚

实例删除不级联删除审计。历史默认永久保留；管理员先配置组织审核过的期限，再归档、下载、校验和显式清理精确 ID。已改变的记录、活跃审批及待发送通知不能被旧归档清理。归档保存在数据库，外部备份后明确删除服务器副本才释放空间；不可恢复的删除必须慎重。

不自动逆向迁移数据库。跨 0.4/0.5 的身份、预算与任务协议不兼容，不能只回滚某个组件。先停止新任务并恢复配套应用版本及升级前完整数据库备份；对窗口内已发生的真实 VM 变更做人工核对，避免数据库恢复导致重复创建或误删。任何旧迁移都不得原地修改。
